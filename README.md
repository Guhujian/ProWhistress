# ProWhistress: Sentence Stress Detection Models

This repository contains the official implementation for both English and Chinese versions of the ProWhistress model, submitted to **Interspeech 2026** Paper ID 1303.

## 📂 Project Structure

* [**English Model (ProWhistress-en)**](ProWhistress-en)
* [**Chinese Model (ProWhistress-cn)**](ProWhistress-cn)

Please click the links above to access the respective subdirectories for detailed usage instructions.

### 📢 Dataset Release Plan
The complete **SinoStress** (~12 hours) and **SinoStress-Real** (~3 hours) datasets are currently undergoing final privacy and metadata formatting. To strictly comply with the double-blind review policy, the full datasets will be publicly released upon paper acceptance. 

For review purposes, a small sample dataset is included in each model subdirectory to ensure all scripts are executable.
