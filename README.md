\# ProWhistress: Sentence Stress Detection Models



This repository contains the official implementation for both English and Chinese versions of the ProWhistress model, submitted to \*\*Interspeech 2026\*\*.



\## 📂 Project Structure

\- \[\*\*ProWhistress-en/\*\*](./ProWhistress-en/): Implementation and instructions for the \*\*English\*\* model.

\- \[\*\*ProWhistress-cn/\*\*](./ProWhistress-cn/): Implementation and instructions for the \*\*Chinese\*\* model.



Please refer to the respective subdirectories for detailed usage instructions and environmental setup.
